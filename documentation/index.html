Kidora – Preschool & Kindergarten HTML Template

Modern, responsive, and accessible template built with Bootstrap 5 and vanilla JavaScript.

Get Started Credits

1. Introduction

Kidora is a modern, responsive Preschool & Kindergarten HTML Template designed for educational institutions such as preschools, daycares, and child learning centers. Built with Bootstrap 5, semantic HTML5, and vanilla JavaScript.

  • Version: 1.0.0
  • Author: nano_theme
  • Created: October 2025
  • Compatibility: Bootstrap 5.x, HTML5, CSS3, JavaScript (ES6)

2. Installation & Setup

Quick setup guide for getting started with Kidora:

Step 1: Extract Files

  • Download and extract the Kidora template files
  • Upload all files to your web server or local development environment
  • Ensure proper file permissions are set

Step 2: File Structure

Kidora/
├─ assets/
│  ├─ css/        → All style files (style.css, page-specific CSS)
│  ├─ js/         → All JS scripts (active.js, page-specific scripts)
│  ├─ img/        → Images and placeholder assets
│  └─ fonts/      → Custom fonts (if any)
└─ *.html         → Individual pages (About, Blog, Contact, etc.)

Step 3: Basic Setup

  • Open any HTML file in your browser to view the template
  • All pages are ready to use with no additional setup required
  • Bootstrap 5 and other dependencies are loaded locally
  • No server-side requirements or database needed

Step 4: Customization

  • Edit HTML files to modify content and structure
  • Customize CSS files in assets/css/ directory
  • Modify JavaScript files in assets/js/ for functionality changes
  • Replace images in assets/img/ with your own content
  • Update contact information and social media links

3. HTML Structure

Each page uses semantic HTML5 and a consistent structure:

<!DOCTYPE html>
<html lang="en">
  <head>
    <!-- Meta tags, SEO, Social sharing -->
    <!-- Bootstrap CSS and Icons -->
    <!-- Custom CSS files -->
  </head>
  <body>
    <!-- Preloader -->
    <div id="preloader">...</div>
    
    <!-- Header/Navigation -->
    <header>...</header>
    
    <!-- Main Content Sections -->
    <main>...</main>
    
    <!-- Footer -->
    <footer>...</footer>
    
    <!-- JavaScript Files -->
    <script src="assets/js/active.js" defer></script>
  </body>
</html>

Each page includes preloader, header navigation, main content sections, footer, and page-specific JavaScript functionality.

4. CSS & Customization

Edit global and page-specific styles. Use CSS variables under :root to change theme colors: 

:root {
  --doc-color-primary: #7c4dff;
  --doc-color-secondary: #00bcd4;
  --doc-color-bg: #0b1020;
  --doc-color-card: #0f1630;
  --doc-color-text: #e8edff;
}

Responsive breakpoints follow Bootstrap 5 conventions (xs → xxl).

5. JavaScript Features

  • Scroll animations (IntersectionObserver)
  • Smooth scrolling, active TOC highlighting
  • Sticky/Collapsible sidebar for mobile
  • Counter example & event listener best-practices
// Counter example
let k = 0; const end = 100;
const tick = () => { if (k < end) { k++; requestAnimationFrame(tick); } };
requestAnimationFrame(tick);

6. Images & Icons

  • Place all images under assets/img/
  • Use compressed JPG/PNG (≤ 500 KB)
  • Favicon: assets/img/favicon.ico
  • Social share: assets/img/cover.jpg
  • Icons: Bootstrap Icons / Lucide

7. SEO & Accessibility

All pages should include SEO & social meta + favicon and have descriptive alt on images. Check focus states and color contrast. 

<meta name="description" content="Kidora – A joyful place for kids to learn and grow.">
<link rel="icon" href="assets/img/favicon.ico">

8. Performance Tips

  • Lazy-load images and set width/height to reduce CLS
  • Minify CSS/JS and remove unused libraries
  • Preconnect to critical origins (e.g., Google Fonts)
<img src="assets/img/demo.jpg" width="1200" height="800"
     loading="lazy" decoding="async" alt="Happy kids in class">

12. Troubleshooting

Common issues and solutions:

Template Not Loading Properly

  • Check that all files are uploaded correctly
  • Ensure proper file permissions are set
  • Verify that packages are accessible
  • Clear browser cache and reload

Images Not Displaying

  • Check image file paths are correct
  • Ensure images are uploaded to assets/img/ directory
  • Verify image file formats are supported
  • Check file permissions on image files

Styling Issues

  • Ensure CSS files are loading properly
  • Check for CSS syntax errors
  • Verify Bootstrap CSS is loading from local
  • Clear browser cache

JavaScript Not Working

  • Check browser console for JavaScript errors
  • Ensure JavaScript files are loading properly
  • Verify all dependencies are loaded
  • Check for conflicts with other scripts

Mobile Responsiveness

  • Ensure viewport meta tag is present
  • Check Bootstrap CSS is loading correctly
  • Verify responsive classes are applied
  • Test on actual devices, not just browser dev tools
